# Medicine Inventory Management System

##  Project Overview

The **Medicine Inventory Management System** is a Python-based application designed to manage medicine stock and inventory efficiently. It helps users maintain medicine records, monitor available stock, manage sales, handle restocking, and generate invoices.

This project aims to simplify medicine inventory management and reduce manual record-keeping.

## ✨ Features

- **Medicine Inventory Management:** Maintain medicine inventory records.
- **Add and Manage Stock:** Manage available medicines and their quantities.
- **Restock Medicines:** Update inventory when new medicines are added.
- **Sell Medicines:** Process medicine sales and update stock quantities.
- **Invoice Generation:** Generate invoices for medicine sales.
- **Data Storage:** Store inventory information using a text file.

## 🛠️ Technologies Used

- Python
- File Handling
- Object-Oriented / Modular Programming (where applicable)

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Prakrisht/Medicine-Inventory.git
```

### 2. Navigate to the Project Folder

```bash
cd Medicine-Inventory
```

### 3. Run the Application

```bash
python main.py
```

If your system uses Python 3 through the `python3` command, run:

```bash
python3 main.py
```

## 🚀 How to Use

1. Run the application using `main.py`.
2. Follow the instructions displayed by the application.
3. Manage medicine inventory.
